# Model files

Every model the app can download is listed in the registry at
`server/src/data/model-registry.json`. The [Model Manager](studios/model-manager.md) reads the
same file, so what you see there is what is listed here. The tables below are generated from
the registry by `node tools/docs/build-docs.mjs`; edit the registry, not this page.

Roles: `dit` is the diffusion transformer that renders audio, `lm` is the language model
that plans the song, `vae` decodes latents to audio, and the remaining roles are text
encoders, post-processing models, separation models and runtime libraries. A quant label
such as `Q8_0` or `Q4_K_M` is the GGUF quantisation; lower numbers mean smaller files and less
VRAM at some cost in quality. [Getting higher quality output](quality.md) explains which
precision to pick for each backend.

Files download from Hugging Face into the app's `models/` folder. You can also drop your own
GGUF files there; the Model Manager lists anything it recognises by role.

## Packs

A pack is a named bundle of files that gets one backend working end to end. Start with the
Quick Start pack for ACE-Step 1.5; add a pack per backend you want to use.
